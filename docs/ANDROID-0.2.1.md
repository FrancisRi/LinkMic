# Android 0.2.1 界面修复与优化

本版对应实机反馈的四项安卓界面调整，可直接覆盖安装 Android 0.2.0，继续配合 Windows 0.3.0 使用。
包名、签名和设备凭据格式不变。正常覆盖安装会保留已记住的电脑，无需重新配对；请勿先卸载或清除应用数据。

## 连接方式切换

修复 Wi-Fi 切回蓝牙后电脑 IP 输入框仍然显示的问题。
MaterialButtonToggleGroup 的选中回调可能先通知新按钮，再更新另一按钮的 checked 状态。
旧逻辑在回调内读取 Wi-Fi 按钮，短暂读到蓝牙和 Wi-Fi 都选中的状态，导致输入框残留。
现在使用回调明确给出的新连接方式，同时更新 IP 输入框与操作说明，不依赖另一按钮的过渡状态。

原生控件回归用例在修复前稳定失败于第一次 Wi-Fi → 蓝牙切换；修复后覆盖页面重建和连续五轮切换。
最小复现不需要真实配对记录，因此不通过模拟 Android Keystore 掩盖控件问题。

## 视觉调整

- 顶部工具栏和计时卡片间距由 12dp 降至 4dp，保留系统状态栏、刘海及导航栏所需安全区域。
- 计时卡片的内边距与文字间距收紧，默认字号下高度约从 160dp 降至 122dp；时间数字使用等宽粗体，长时间仍能自动缩小字号。
- 使用更柔和的绿色、统一的 24dp 卡片圆角、细边框和清晰的标题层级。Android 12+ 继续支持系统动态配色，深色模式保留独立颜色。
- 连接方式加入小图标；设置、配对和电平各自归入卡片。主操作区保持固定，表单在小屏及键盘弹出时可滚动。
- 启动器图标使用独立的 108dp 前景资源，主体线性缩小约 20%，增加不同裁剪形状下的留白。通知栏麦克风图标保持原来的独立资源，Android 13+ 单色图标同步使用新留白。

计时刷新频率、录音服务、配对协议和音频传输代码没有改变。

## 验证与实机复测

验证脚本：`scripts/verify-android.ps1`；工具和依赖已缓存时可加 `-Offline`。
测试包含真实 Material 控件切换、页面重建、计时刷新、深浅色原生渲染、小屏大字体和实际 AdaptiveIconDrawable 图标渲染。
APK 签名与旧版一致，安装包校验记录见 `artifacts/tests/release-030-android021-verification.json`。

本轮没有启动 ADB 或操作物理手机。请在原手机覆盖安装后复测：退出重进 → Wi-Fi → 蓝牙，确认 IP 输入框隐藏；再检查桌面图标、深浅色界面及原有免码连接。

安装包：`artifacts/LinkMic-Android-0.2.1-debug.apk`。
